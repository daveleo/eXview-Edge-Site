eXview Edge — Crestron Control Module

A SIMPL+ module for Crestron control processors that gives a touchpanel full control of an eXview Edge or eXview AIO screen: power, volume, brightness, source and HDMI signal status.

01What it is

A SIMPL+ module (.usp) you drop into a SIMPL Windows program. Once wired to an eXview screen, it exposes simple joins a touchpanel program can use directly — no need to know anything about the screen's own command protocol.

Works with eXview Edge and eXview AIO
Transport network (UDP) or RS-232
Platform SIMPL Windows, 3-Series / 4-Series processors

The compiled module is available as a single download.

02Wiring it up

  1. Add the transport symbol

    Most installs use a UDP/IP Communications symbol pointed at the screen's IP address, port 8600. Going over RS-232 instead, use a COM port symbol set to 115200 baud, 8-N-1.

  2. Connect the module to it

    Wire the module's ToDevice output to that symbol's transmit line, and its FromDevice input to the receive line. That's the only wiring the module itself needs beyond your button/feedback joins.

  3. Turn polling on

    Hold the PollEnable input high. The screen never reports changes on its own, so this is what keeps the touchpanel's feedback in sync — including changes made locally at the screen (remote control, on-screen menu).

    How often it polls is set by the PollIntervalSec parameter, see Section 04.

03What the signals do

Every input is a plain button or slider; every output is plain feedback a touchpanel can bind to directly.

Power

Power control

  • Standby — quick screen-off, screen stays online
  • Shutdown — deep power-down
  • WakeUp — wakes it back up, either state
  • Reboot, Query

Feedback (AwakeFb / BlackoutFb / StandbyFb, plus a combined PowerStateFb) tells the panel which of the three states the screen is actually in.

Volume & brightness

Sliders

  • VolumeSet / BrightnessSet — 0–100

VolumeFb / BrightnessFb report the current level back, so a slider on the panel always shows where the screen actually is, not just where it was last set to.

Source

Input selection

  • SrcAndroid, SrcHdmi1–4 — one button per source

Per-source feedback shows the active input, and a separate set of Input_Active_Fb signals shows which HDMI ports actually have a live cable plugged in — useful for greying out inputs with nothing connected.

Parameters

Timing settings

  • PollIntervalSec — how often it polls (default 10s)
  • ShutdownBusySec / RebootBusySec — how long the screen is expected to be unreachable after each

A BusyFb output stays high for that long, so the panel can show “please wait” instead of looking unresponsive while the screen restarts.

04Good to know

While the screen is in Standby, volume/brightness/source can't be read. The module shows those as unknown rather than an old, possibly wrong reading — they come back automatically once the screen is awake again. This is expected, not a fault.
Four HDMI buttons, even on two-input screens. The module supports HDMI1–4 for the eXview AIO family. On an eXview Edge unit with only HDMI1/2, the extra buttons simply do nothing — there's no error, they're just inactive.
Shutdown and Reboot take the screen offline for a while. Expect roughly a minute of no response while it restarts — that's what BusyFb and the timing parameters in Section 03 are for.

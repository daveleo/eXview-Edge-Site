Updating eXview AIO / Edge

Firmware update procedure

1. Prerequisites

  1. USB-A drive.
  2. Keyboard and mouse.
  3. Latest firmware package.
  4. Android menu password: EXPcontrol.
Firmware package
Download the newest firmware package from:
https://nextcloud.expromo.eu/s/NrWcbTKJPgEeEcF

2. Precautions

  • All Android configurations will be erased.
  • Take note of the current IP/network settings before proceeding. They must be re-established after the update.
  • Always use the firmware file supplied in the newest firmware package.

3. Prepare the USB Drive

  1. Use the firmware file named allupgrade_3588_64G_8G.img.
  2. Create a folder named upgrade_3588 in the root of the USB drive.
  3. Place allupgrade_3588_64G_8G.img inside the upgrade_3588 folder.
Required USB structure:
USB drive / upgrade_3588 / allupgrade_3588_64G_8G.img

4. Update Android

  1. Before updating, confirm that you have recorded the current Ethernet/IP settings to avoid loss of network control after the firmware update.
  2. Change the current source of the eXview screen to Android.
  3. Plug the USB drive into any available USB port on the eXview AIO / Edge.
  4. A notification window will pop up.
  5. Use the remote control to accept the update, or connect a keyboard/mouse to another available USB port and accept the update.
  6. Wait until the update is finished. The screen will reboot automatically.

5. After the Update

  • Restore the required Ethernet/IP settings.
  • Restore the required standby-time settings.
  • Verify that the normal video source, network control, and other required functions operate correctly.

When the picture is unusable · Expromo-directed recovery

eXview Edge — Screen Capture and Control via ADB

If the screen is blank or too distorted to use, and Expromo support has told you it needs a firmware upgrade or a factory reset, you can still reach the Android system inside it and do that — without the LED wall showing anything useful.

01What you need

This only works if Expromo support has already diagnosed the issue and told you a firmware upgrade or factory reset is the fix. It mirrors the screen's own Android interface onto a laptop over the network, so you can operate it even though the physical picture isn't usable.

USB drive with the LDataAdbConfigEnable file on it
PC on the same network as the screen
ADB/scrcpy tool folder

The tool folder (RUN-ME.exe, ADB, scrcpy, and LDataAdbConfigEnable) is available as a single download.

Download the tool folder

02Connect and mirror the screen

  1. Enable ADB on the screen

    Copy the LDataAdbConfigEnable file — on its own, nothing else needed — to the root of a USB flash drive. Plug that drive into the eXview Edge screen. This turns on the debug connection the next step needs.

  2. Run RUN-ME.exe and pick your screen

    In the tool folder, double-click RUN-ME.exe. It scans the network automatically and lists any eXview screens it finds:

    Found 1 screen(s):
      1) eXviewEDGE  -  10.20.30.55
      0) You don't see your screen? Type IP here

    Enter the number for your screen. If it isn't listed, type its IP address at the same prompt instead — you can find it in eXconfig under Link Info if needed. Once connected, a mirror window opens automatically.

    Can't connect? Double-check the USB drive from step 1 is plugged in, and that the IP address is correct.

03Do what Expromo told you to do

Once the mirror window is open, use the mouse to navigate exactly as you would on the screen itself: Apps & Settings → Settings.

If told: firmware upgrade

Check for updates

Settings → About → Check for updates

Shows the current software version and starts the update if one is available.

If told: factory reset

Restore factory settings

Settings → Restore → Restore factory settings

Clears app data, user data, and any downloaded apps.

Only do this if Expromo told you to. A factory reset clears application data, user data, and downloaded apps, and can't be undone from here. If you're not sure which path applies, stop and confirm with Expromo support before continuing.

04Scope of this guide

There is also a hidden factory/debug menu on these screens, used internally by Expromo for deeper diagnostics. It's not covered here and isn't needed for a normal firmware upgrade or factory reset — both are reachable through the regular Settings menu shown above. Only use the factory/debug menu if an Expromo technician walks you through it directly.

For anyone on-site handling a screen with an unusable picture, under Expromo support's direction. If the screen is still unreachable after checking the USB drive, IP address, and network, contact Expromo support.
